# Handoff Instructions

When development is handed to an engineering agent, it should first read, in this order:

1. `PROJECT_STATE.md`
2. `docs/ARCHITECTURE.md`
3. `docs/ROADMAP.md`
4. `docs/RESEARCH_ARCHITECTURE_SOURCE.md`
5. Existing code and latest CI run

Do not jump directly to HDR or AI. First make Phase 01 session qualification reliable on actual hardware.

The first engineering goal after the initial GitHub push is:

> Every lens shown in the normal UI must be a genuine user-usable lens, and every RAW badge must be backed by a verified session combination rather than static metadata alone.
